DualCue - 雙語字幕與學習講義下載首頁常見問題

LAST UPDATED 2026-08-24

隱私政策

DualCue - 雙語字幕與學習講義下載以資料最小化與使用者主動操作為原則。不建立帳號、不投放廣告，也不包含使用行為分析 SDK。介面支援繁中、簡中、日文與韓文；翻譯來源固定為英文，目標可選繁中、簡中、日文或韓文。

首次同意與處理範圍

首次使用或從舊版升級時，DualCue 會先顯示 v3 資料處理說明並等待使用者按下「同意並翻譯」。由於新增 Bilibili 固定網域與字幕路徑，已接受 v2 的使用者升級後需要重新確認一次，但不會清除設定、API Key 或收藏。同意前不讀取目前分頁的網址、標題、字幕或網頁文字，也不載入本機收藏。同意後 YouTube 與 Bilibili 會自動處理英文字幕；Netflix／Disney+ 只在播放且平台已顯示英文字幕時處理可見字幕與播放時間。

  • 網站內容：使用者啟動功能後，處理目前網頁文字、YouTube／Bilibili 字幕，或 Netflix／Disney+ 畫面上可見的字幕；無字幕轉錄另處理使用者主動擷取的 YouTube／Bilibili 分頁音訊。
  • 瀏覽活動：為辨識來源、返回收藏頁面及控制播放器，處理目前頁面的網址、標題、平台、播放時間與使用者要求的重播／循環操作。
  • 驗證資訊：只有瀏覽器能把擴充功能本機儲存限制於受信任環境時，才允許使用者保存 BYOK API Key；不支援此保護的瀏覽器會停用 BYOK。金鑰不會公開顯示。

本機保存的資料

  • 設定、按目標語言分區的本機術語表，及允許保存時由使用者自行提供的 API Key 儲存在瀏覽器的 WebExtension 本機儲存空間。
  • 翻譯快取及句子收藏儲存在擴充功能的 IndexedDB；來源與目標語言、最近機器譯文、翻譯服務／模型、翻譯時間與人工編輯狀態會與內容一起保存，避免跨語言誤用並支援恢復。這些收藏與編輯不會同步到開發者伺服器。
  • 網頁閱讀偏好按網站 hostname 儲存在擴充功能本機空間，包括目標語言、翻譯引擎、翻譯範圍與顯示樣式。載入偏好不會自動讀取頁面文字或呼叫翻譯服務。
  • 資料不會自動同步到開發者或第三方伺服器；移除擴充功能時，相關本機資料依瀏覽器的擴充功能資料政策處理。

翻譯內容的傳送

  • 瀏覽器本機翻譯：只在瀏覽器提供相容 Translator API 時使用，文字留在裝置上處理；不支援時會明確停用，且不會自動切換到 BYOK。
  • YouTube 翻譯：字幕請求由瀏覽器送往 YouTube。
  • Bilibili 字幕：擴充功能在當前分頁讀取播放器已取得的字幕 metadata，或以當前影片的 bvid／cid 請求 Bilibili 字幕清單；字幕內容只從 Bilibili 或其影音 CDN 的 HTTPS 網址取得。DualCue 不讀取影音串流網址、不儲存 cookie，也不繞過登入或付費限制。
  • Netflix／Disney+：在 v3 同意後，擴充功能只於影片實際播放且平台已顯示英文字幕時讀取可見字幕與 HTML5 播放時間；不讀取影音串流網址、DRM 或帳號資料。
  • BYOK 雲端服務：自動首譯永遠不使用 BYOK。只有使用者在「翻譯設定」選定服務並按下「用 AI 重新翻譯」後，要求處理的字幕、網頁文字或講義內容才會送往該服務。可選服務包括 OpenAI、Google Gemini、DeepSeek、Google Cloud Translation 與 Microsoft Translator；資料由使用者自己的 API 帳戶直接傳送，其處理方式受所選服務的政策約束。使用者開啟語境或使用本機術語表時，只有 OpenAI、Gemini、DeepSeek 會隨目前翻譯工作收到相鄰參考句或該目標語言的術語快照；其他路徑不會收到這些資料。
  • OpenAI-compatible 本地模型：只有使用者選擇此路徑並按下開始後，要求處理的字幕或網頁文字才會送到使用者指定的 localhost、127.0.0.1 或 ::1 服務。「試譯 20 句並估時」只送出目前影片最前 20 個可用字幕 cue 到該 loopback 服務，用於估算整片時間；不會啟動完整翻譯、不寫入完整工作 checkpoint。API Key 選填；DualCue 不啟動模型伺服器、不接受 LAN／遠端位址，也不會自動改用雲端服務。

切換介面語言不會修改翻譯目標，也不會啟動任何翻譯。舊使用者升級後保留既有目標語言；新安裝只使用瀏覽器 UI 語言選擇初始介面與目標。

音訊轉錄

只有瀏覽器同時支援分頁音訊擷取與離屏處理，而且使用者在沒有字幕的 YouTube／Bilibili 影片按下開始生成字幕後，擴充功能才會擷取目前分頁的音訊批次並傳送到使用者設定的 OpenAI 帳戶做英文轉錄。此路徑會產生使用者帳戶的 API 費用；轉錄後的文字優先使用 Chrome 本機 Translator 翻譯，不會因音訊授權另外發送雲端文字翻譯。本機翻譯不可用時會保留英文，只有使用者之後明確選擇 AI 重譯才會產生新請求。Bilibili 結果是重新轉錄，不是 OCR 擷取畫面中的燒錄字幕。停止、換片或關閉頁面時會結束擷取。Firefox 桌面版不支援此路徑，控制項會保持可見但停用。

網頁存取

YouTube、Bilibili、Netflix 與 Disney+ 是核心影音 Adapter，因此擴充功能只宣告這些明確網域的固定權限；影音 Adapter 仍受 v3 同意、播放狀態或英文字幕條件限制。一般網頁只有在使用者按工具列 DualCue 圖示後，才使用該分頁的臨時授權或申請目前單一 exact origin，完成後自動走免費本機翻譯；單純切換分頁不會讀取文章。擴充功能不會在安裝時取得永久讀取所有網站的權限；密碼、表單、付款、可編輯及程式碼區域會被排除。整頁翻譯完成後可使用瀏覽器列印／另存 PDF；此步驟只輸出目前頁面的原文與既有譯文，不會重新翻譯或呼叫 Provider。

瀏覽器能力差異

Chrome／Edge 使用 Side Panel；相容的 Chromium 品牌缺少 Side Panel 時會改用單一工作區分頁；Firefox 桌面版使用原生 Sidebar。Firefox 不提供 DualCue 所需的本機 Translator、分頁音訊擷取與離屏處理時，相關功能會明確停用；既有字幕、網頁內容、收藏、手動編輯、SRT／TXT、A4 講義與列印仍依使用者操作處理。任何平台能力缺少時都不會自動改用可能付費的服務。

自願支持

所有功能免費。側欄底部的「支持 DualCue」只會以新分頁開啟設定的 PayPal.Me HTTPS 公開收款頁；該外部頁可能顯示 PayPal 驗證的收款帳戶姓名。DualCue 不處理付款資料、不建立訂閱或功能權益、不顯示提醒、不記錄點擊，也不傳送任何支持相關資料。

我們不做的事

  • 不出售個人資料。
  • 不使用翻譯內容訓練模型。
  • 不把 API Key 寫入日誌、下載、測試或原始碼。
  • 不在沒有明確操作時呼叫付費 API。

商店政策與資料限制

無論從 Chrome Web Store、Microsoft Edge Add-ons 或 Firefox Add-ons 安裝，資料都只用於提供或改善雙語字幕、翻譯、收藏與學習講義這個單一學習用途；不會用於個人化廣告、信用評估或資料轉售，也不允許開發者人工閱覽使用者內容，法律要求或使用者為特定支援明確同意的情況除外。Chrome Web Store 版本另遵守 Chrome Web Store User Data Policy 與 Limited Use requirements；從 Google API 收到的資訊同樣遵守上述政策與限制。
