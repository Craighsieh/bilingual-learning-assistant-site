DualCue - 雙語字幕與學習講義下載首頁常見問題

LAST UPDATED 2026-07-24

隱私政策

DualCue - 雙語字幕與學習講義下載以資料最小化與使用者主動操作為原則。不建立帳號、不投放廣告，也不包含使用行為分析 SDK。介面支援繁中、簡中、日文與韓文；翻譯來源固定為英文，目標可選繁中、簡中、日文或韓文。

首次同意與處理範圍

首次使用時，DualCue 會先在側欄說明資料處理方式並等待使用者按下「同意並開始使用」。同意前不讀取目前分頁的網址、標題、字幕或網頁文字，也不載入本機收藏。使用者可選擇不按下同意，此時學習功能不會啟動。

  • 網站內容：使用者啟動功能後，處理目前網頁文字、YouTube 字幕，或 Netflix／Disney+ 畫面上可見的字幕；無字幕轉錄另處理使用者主動擷取的分頁音訊。
  • 瀏覽活動：為辨識來源、返回收藏頁面及控制播放器，處理目前頁面的網址、標題、平台、播放時間與使用者要求的重播／循環操作。
  • 驗證資訊：使用者自行提供的 BYOK API Key 只保存在擴充功能的本機儲存空間，且不會公開顯示。

本機保存的資料

  • 設定、按目標語言分區的本機術語表，及使用者自行提供的 API Key 儲存在 chrome.storage.local。
  • 翻譯快取及句子收藏儲存在擴充功能的 IndexedDB；來源與目標語言、最近機器譯文、翻譯服務／模型、翻譯時間與人工編輯狀態會與內容一起保存，避免跨語言誤用並支援恢復。這些收藏與編輯不會同步到開發者伺服器。
  • 網頁閱讀偏好按網站 hostname 儲存在擴充功能本機空間，包括目標語言、翻譯引擎、翻譯範圍與顯示樣式。載入偏好不會自動讀取頁面文字或呼叫翻譯服務。
  • 資料不會自動同步到開發者或第三方伺服器；移除擴充功能會由 Chrome 清除相關本機資料。

翻譯內容的傳送

  • Chrome 本機翻譯：文字在裝置上處理。
  • YouTube 翻譯：字幕請求由瀏覽器送往 YouTube。
  • Netflix／Disney+：只有使用者明確開始後，擴充功能才讀取目前分頁可見的字幕與 HTML5 播放時間；不讀取影音串流網址、DRM 或帳號資料。
  • BYOK 雲端服務：只有使用者選定服務並按下開始後，要求處理的字幕、網頁文字或講義內容才會送往該服務。可選服務包括 OpenAI、Google Gemini、DeepSeek、Google Cloud Translation 與 Microsoft Translator；資料由使用者自己的 API 帳戶直接傳送，其處理方式受所選服務的政策約束。使用者開啟語境或使用本機術語表時，只有 OpenAI、Gemini、DeepSeek 會隨目前翻譯工作收到相鄰參考句或該目標語言的術語快照；其他路徑不會收到這些資料。

切換介面語言不會修改翻譯目標，也不會啟動任何翻譯。舊使用者升級後保留既有目標語言；新安裝只使用 Chrome UI 語言選擇初始介面與目標。

音訊轉錄

只有使用者在沒有字幕的 YouTube 影片按下「開始生成 AI 字幕」後，擴充功能才會擷取目前分頁的音訊批次並傳送到使用者設定的 OpenAI 帳戶。停止、換片或關閉頁面時會結束擷取。

網頁存取

Netflix／Disney+ 是首版核心影音 Adapter，因此擴充功能只宣告這兩個明確網域的固定權限；但只有使用者按下開始後才會讀取目前頁面可見字幕。一般網頁優先使用 Chrome 的 activeTab；固定側欄切換到新分頁時，只有使用者按下「允許目前網站」才會申請該單一網域。擴充功能不會在安裝時取得永久讀取所有網站的權限；密碼、表單、付款、可編輯及程式碼區域會被排除。

自願支持

所有功能免費。只有開發版本在建置時設定有效的 GitHub Sponsors HTTPS 網址，側欄底部才會顯示「支持 DualCue」連結。它只會開啟 GitHub Sponsors；DualCue 不處理付款資料、不建立訂閱或功能權益、不顯示提醒、不記錄點擊，也不傳送任何支持相關資料。

我們不做的事

  • 不出售個人資料。
  • 不使用翻譯內容訓練模型。
  • 不把 API Key 寫入日誌、下載、測試或原始碼。
  • 不在沒有明確操作時呼叫付費 API。

Chrome Web Store Limited Use

DualCue 對使用者資料的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use requirements。資料只用於提供或改善雙語字幕、翻譯、收藏與學習講義這個單一學習用途；不會用於個人化廣告、信用評估或資料轉售，也不允許開發者人工閱覽使用者內容，法律要求或使用者為特定支援明確同意的情況除外。從 Google API 收到的資訊同樣遵守上述政策與限制。
