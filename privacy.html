隱私政策

雙語學習助手以資料最小化與使用者主動操作為原則。首版不建立帳號、不投放廣告，也不包含使用行為分析 SDK。

本機保存的資料

  • 設定及使用者自行提供的 API Key 儲存在 chrome.storage.local。
  • 翻譯快取及句子收藏儲存在擴充功能的 IndexedDB。
  • 資料不會自動同步到開發者或第三方伺服器；移除擴充功能會由 Chrome 清除相關本機資料。

翻譯內容的傳送

  • Chrome 本機翻譯：文字在裝置上處理。
  • YouTube 翻譯：字幕請求由瀏覽器送往 YouTube。
  • BYOK 雲端服務：只有使用者選定 Provider 並按下開始後，待翻譯文字才會送往該 Provider。其處理方式受該服務的政策約束。

音訊轉錄

只有使用者在沒有字幕的 YouTube 影片按下「開始生成 AI 字幕」後，擴充功能才會擷取目前分頁的音訊批次並傳送到使用者設定的 OpenAI 帳戶。停止、換片或關閉頁面時會結束擷取。

網頁存取

一般網頁翻譯使用 Chrome 的 activeTab 權限，只在使用者開啟側欄後注入目前分頁。擴充功能不要求永久讀取所有網站；密碼、表單、付款、可編輯及程式碼區域會被排除。

我們不做的事

  • 不出售個人資料。
  • 不使用翻譯內容訓練模型。
  • 不把 API Key 寫入日誌、下載、測試或原始碼。
  • 不在沒有明確操作時呼叫付費 API。

聯絡方式

隱私或支援問題可透過 開發者 GitHub 頁面聯絡。
