Never open study IndexedDB, attach answers/attempt IDs, auto-include current URL/query, collect visitor email or credentials, or expose mailbox access/activation secrets.
- AC3: Exact fixed HTTPS FormSubmit public AJAX endpoint, POST JSON, credentials omitted, bounded 20-second timeout. Success requires HTTP ok and parsed success true or string true (verify the real service format); non-JSON, network failure, HTTP error, false success and timeout never display sent. No automatic retry. An uncertain result explains it may have reached the service and preserves input/report reference for manual retry. Do not promise guaranteed email delivery or true server idempotency.

After confirmed acceptance keep the same form locked until an explicit send-another action resets the typed description; preserve contextual form/question. In-memory reference remains stable for an unchanged retry; server may receive duplicates after uncertain failures, owner can correlate by reference. No localStorage/sessionStorage/draft persistence added.

Fields bounded client-side; provider owns server validation and filtering, client checks are usability not authorization. Do not implement or claim unverified CAPTCHA/inbox privacy. ## Resolved pre-code challenges

DeepSeek and Muse independently challenged this contract. Supported corrections: fixed canonical URL by construction; explicit `success === true || success === "true"` acknowledgement after HTTP ok (real activation response was HTTP200/success="false"); stable random DC-UUID for unchanged in-memory retries; hidden honeypot with autocomplete off/tabindex -1/aria-hidden; visible enabled send-another; reload-loss disclosure; consistent UTF-16 maxlength matching browser behavior. No true server idempotency guarantee. Fetch referrerPolicy is origin, so the service receives only the source website origin, never the current path or query in Referer. The real service rejected no-referrer with HTTP200/success="false" despite the documented _url field; this compatibility correction keeps strict query minimization and is covered by tests. Public recipient alias is not a mailbox/archive key. No SMTP, Google mailbox credentials, archive API key or activation link belongs in the public build.

Runtime gate: recipient activated through owner mailbox; first anonymous alias submission at a second local origin arrived in Gmail with all required context and no synthetic PRIVATE/SECRET query values.
